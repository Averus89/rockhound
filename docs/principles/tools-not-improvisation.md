# Use the tools, don't improvise

For routine steps use the repo's tools (its check command, scripts in `scripts/`, and — when nightshift runs here — `ns`). When a tool is missing or awkward, [report it as friction](report-friction.md) instead of inventing a one-off command.

Why: a tool behaves the same every time and can be tested; an improvised command fails in a new way each time and often needs an approval.
