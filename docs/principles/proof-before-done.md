# Done means proven

Don't call it done before the repo's check has run and — for a deployed change — before you have called it on the live address. Deterministic evidence first (tests, measurements in code), screenshots or recordings only on top. Capture evidence from the real build; never write it. What you cannot check, say so in the PR.

Why: merged is not deployed and deployed is not working; the owner reads the evidence, not the code.
