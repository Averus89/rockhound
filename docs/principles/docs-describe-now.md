# Docs describe how it is now

Write docs in the present tense, as if it had always been this way: no "new", "now", "we used to" or rollout notes. Change the page that already covers the topic instead of adding another. What changed and why belongs in git history and the decision records.

Why: a reader needs the current state; history mixed into it gets taken for a fact, and two pages on one topic soon disagree.
