How it reads

From a number on your HUD to a name, in a few milliseconds.

  1. 1

    Ping

    Fly as usual and ping. When the scanner shows a signature next to the orange map pin, Rockhound finds the pin and crops the number around it.

    Captures the game window, nothing else

  2. 2

    Read

    The HUD always uses the same digit font, so Rockhound matches each digit against stored templates instead of running a general OCR engine. Several frames vote on the result.

    About 3 ms per read

  3. 3

    Name it

    A signature is a base value times the number of rocks. Rockhound looks it up in the signature table and shows the best match, with anything else it could be underneath.

    Table from the game files, SC 4.10.2

The app

A main window, and an overlay that stays out of the way.

  • Overlay on top of the game. Click-through, always on top, showing just the value and what it is.
  • Where you are. Some numbers mean different things in space and on a planet. Tell Rockhound where you are and it puts the right answer first.
  • Up to date after a patch. The app checks for a newer signature table at startup and falls back to the one it ships with.
  • Small and quick. Written in Rust with a Tauri window, so it starts fast and stays light while the game runs.
