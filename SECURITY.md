# Security policy

## Supported versions

Only the latest release of Rockhound gets security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately, not in a public issue, pull request
or discussion.

Use GitHub's private vulnerability reporting: open the repository's
**Security** tab and click **Report a vulnerability**
(https://github.com/Averus89/rockhound/security/advisories/new).

Include what you found, how to reproduce it, the affected version, and the
impact you expect. You can expect an acknowledgement within 7 days. Once a fix
is released you will be credited in the advisory unless you ask not to be.

Rockhound reads the game's screen and the signature table published in this
repository; it does not handle accounts or credentials. Reports about Star
Citizen itself belong with Cloud Imperium Games, not here.
